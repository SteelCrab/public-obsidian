# Terraform s3.tf 설정

#terraform #s3 #aws #정적웹사이트 #static

---

`s3.tf`는 S3 버킷을 생성하고 정적 웹사이트 호스팅을 설정하는 파일입니다.
VPC 외부의 글로벌 서비스(S3)를 Terraform으로 관리합니다.

## 파일 구조

```hcl
resource "aws_s3_bucket" "pista-static" {
  bucket = "pista-static-website-${random_id.suffix.hex}"
}

resource "random_id" "suffix" {
  byte_length = 4
}

resource "aws_s3_bucket_public_access_block" "pista-static" {
  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}

resource "aws_s3_bucket_website_configuration" "pista-static" {
  index_document { suffix = "index.html" }
}

resource "aws_s3_bucket_policy" "pista-static" {
  policy = jsonencode({ ... PublicReadGetObject ... })
}

resource "aws_s3_object" "index" {
  key          = "index.html"
  source       = "${path.module}/index.html"
  content_type = "text/html"
}
```

## aws_s3_bucket 블록

| 항목 | 설명 |
|------|------|
| `bucket` | 버킷 이름 (전역 유니크해야 함) |

> `random_id`를 이용해 버킷 이름 끝에 4바이트 hex suffix를 붙여 유니크성 보장.

## aws_s3_bucket_public_access_block 블록

| 항목 | 설명 |
|------|------|
| `block_public_acls` | ACL 기반 퍼블릭 액세스 차단 |
| `block_public_policy` | 버킷 정책 기반 퍼블릭 액세스 차단 |
| `ignore_public_acls` | 퍼블릭 ACL 무시 |
| `restrict_public_buckets` | 퍼블릭 버킷 접근 제한 |

> 정적 웹사이트 호스팅을 위해 모두 `false`로 설정.

## aws_s3_bucket_website_configuration 블록

| 항목 | 설명 |
|------|------|
| `index_document.suffix` | 기본 문서 파일명 (`index.html`) |

## aws_s3_bucket_policy 블록

| 항목 | 설명 |
|------|------|
| `Action` | `s3:GetObject` - 객체 읽기 |
| `Principal` | `*` - 모든 사용자 |
| `Resource` | `버킷ARN/*` - 버킷 내 모든 객체 |

## aws_s3_object 블록

| 항목 | 설명 |
|------|------|
| `key` | S3 내 파일 경로/이름 |
| `source` | 로컬 파일 경로 (`path.module` = tf 파일 위치) |
| `content_type` | MIME 타입 (`text/html`) |

## 웹사이트 엔드포인트

```
http://<bucket-name>.s3-website-ap-southeast-1.amazonaws.com
```

`terraform apply` 후 출력값으로 확인하려면 `outputs.tf`에 추가:

```hcl
output "website_url" {
  value = "http://${aws_s3_bucket_website_configuration.pista-static.website_endpoint}"
}
```

## 실행 방법

```bash
terraform init
terraform plan
terraform apply
terraform destroy
```
