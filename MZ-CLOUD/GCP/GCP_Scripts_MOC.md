# GCP Scripts MOC

#gcp #scripts #MOC

---

GCP 스크립트 문서 탐색용 허브.
실행 절차는 `[[gcp-scripts]]`에서 확인하고, 모듈별 상세는 아래 문서로 이동한다.

## 빠른 시작

- [[gcp-scripts]] - 전체 실행 가이드 (Workflow, 실행/정리 명령)
- `MZ-CLOUD/GCP/scripts/` - 실제 스크립트 파일 경로

## 공통 설정

- [[gcp-script-env]] - 환경 변수, 공통 함수, `ensure_network()`

## 모듈별 스크립트

- [[gcp-script-network]] - VPC, 서브넷, NAT, 방화벽
- [[gcp-script-vm]] - VM 2대 (Public + Private)
- [[gcp-script-gke]] - GKE 클러스터 구축
- [[gcp-script-cloudsql]] - Cloud SQL (Private IP)
- [[gcp-script-lb]] - HTTP Load Balancer
- [[gcp-script-gcs]] - GCS 정적 사이트 + CDN
- [[gcp-script-simple]] - 심플 VM 2대

## 관련 인덱스

- [[GCP_MOC]] - GCP 전체 목차
- [[GCP_Infra_MOC]] - 인프라 스크립트 상세 목차
